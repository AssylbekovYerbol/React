      Call Stack: runs the synchronous code first: script start, async function start, script end. await pauses the async function and returns control to the caller.
      
        
      Microtask Queue: once the stack is empty, all microtasks run: promise 1, async continuation, promise 2. Promise 2 is added by promise 1, and still runs before any timer.
      
        
      Task Queue: holds the timer callbacks. The Event Loop takes one task, runs it, then empties the microtask queue again (so "microtask inside timer 1" runs before timer 2).
