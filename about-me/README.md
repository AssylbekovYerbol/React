# About Me — React SPA

Self-promotional single page app built with React + Vite.

- Components: `Profile`, `About`, `Skills`, `Contacts` (+ `App`)
- All personal info is in `src/data.js`

## Run locally
```
npm install
npm run dev
```

## Deploy to GitHub Pages
```
npm run deploy
```
Then in the GitHub repo: Settings → Pages → Source: "Deploy from a branch" → branch `gh-pages` / `(root)`.
